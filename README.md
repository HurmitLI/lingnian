## 当前安全边界

- 真实资料模式已经由用户显式启用；敏感文本与媒体使用 AES-256-GCM 静态加密，主密钥保存在当前用户的 Mac 钥匙串。
- 当前 `.env` 使用 FunASR 与通义千问；自动化测试会强制切换到隔离数据库、隔离媒体目录和 mock 模型，不读取正式家庭资料。
- 家庭离线恢复包、恢复口令和主密钥不进入数据库、备份、日志或 Git；完整恢复演练已经通过。
- 本机版真实家庭录音只在本机转写。正式云端版会把录音的临时转写副本发送给阿里云 DashScope 语音识别，录音原件加密保存在家庭私密空间；原始录音不发送给千问大语言模型。
- 转写文字默认不发送千问大语言模型；家人在整场采访开始前可选择一次“AI 自动整理与自然追问”，未开启时使用本地规则整理与安全题库。
- AI 采访采用一问一答的半实时模式；问题优先由通义 CosyVoice 自然声线朗读，失败时才降级到浏览器本机声音。真实资料不发送原始录音；每次采访只需选择一次是否发送转写文字，让千问自动清理口语并生成自然追问，未开启时仍会使用本地规则清理和安全题库。
- 家庭管理员可以指定“讲谁、请谁讲、先聊哪一段”生成一次性采访邀请；受邀家人建账后直接进入已分配的语音采访，中途退出后再登录仍可继续。普通加入家庭的邀请码仍独立保留。
- 原声视频只使用已人工确认故事和原始录音；不克隆声音、不生成新语音、不让照片对口型，素材不上传第三方，新增平台费用为 0 元。
- 公网虚构样片曾用 OneThing RTX 4090 + ComfyUI LivePortrait 做人物动态技术验证，但因口型未受音频驱动、表情和叙事割裂而被验收否决并撤下。真实人物照片仍必须经过本人授权，且不会默认上传第三方。
- 故事情景视频、老照片修复与声音复刻目前只建立了供应商适配、费用和真人授权闸门；人物讲述与故事情景视频已可把后台生成的 MP4 导入本机待验收区。人物视频必须通过声音、嘴型、停顿、表情、叙事和时长六项检查；情景视频必须通过声音、画面自然度、叙事和时长四项检查，未通过不会标记为正式成片。
- 日常服务只绑定 `127.0.0.1`，不得直接暴露公网；手机验收只在用户明确同意后临时开放到同一局域网。
- 公网演示版只包含虚构样片，邀请码和签名密钥只放云端环境变量；未登录时页面、照片和视频直链均被拦截。

## 已实现

- FastAPI `/api/v1`、Pydantic 结构校验和统一脱敏错误；
- SQLite + SQLAlchemy + Alembic 初始迁移；
- 原始音频与派生 WAV 分开保存，MIME/文件头/大小/路径和 SHA-256 校验；
- 持久化转写与整理任务，进程中断后标记为可重试；
- 原始转写、人工校对稿、模型草稿和正式故事分层保存；
- 只有人工确认后才能归档；跳过会清除未归档音频和文本；
- FunASR/Paraformer 本地转写与通义千问兼容接口；
- Next.js 正式响应式 Web，主导航包含家庭首页、开始记录、回忆档案、家族记忆和家庭管理；原声视频降级为档案内的快速影像导出；
- 桌面侧栏与手机底部导航、讲述者切换、最近会话和 URL 刷新恢复；
- 录音 MIME 探测、权限/无设备/占用错误提示、录音计时、试听、移除和确认上传；
- 后台任务进度、页面隐藏暂停轮询、退避等待、网络/超时错误归一化和全局加载/错误页；
- Mac 钥匙串主密钥初始化、家庭离线恢复包下载和安全状态界面；
- 恢复包回读验证和真实资料启用门：未验证恢复包时后端拒绝启用；
- 应用层加密存储：姓名、档案字段、转写、草稿、故事、回忆录和媒体使用独立 nonce 的 AES-256-GCM，密钥、恢复口令不进入 SQLite、`.env`、日志或 Git；
- 本机整库备份与恢复演练：使用 SQLite 在线快照、资产清单和 SHA-256，先在全新目录校验数据库/资产，再用离线恢复包解密抽样文本与全部加密媒体；备份不包含主密钥、恢复口令或恢复包；
- 云模型后端授权门：按家庭、会话、用途和校对稿哈希校验一次性授权，修改文字后旧授权自动失效；
- 七个人生阶段各三道本地题目，优先选择尚未问过的题目；“不要再问”会在后端阻断，“先问我”必须得到本次确认；
- AI 口述史采访：回忆对象与讲述人分离保存；一次点击后自动完成自然语音提问、问题结束后收音、静音判断说完、本地转写、AI 清理口语和标点及下一轮追问；支持“我还在想”“我说完了”“这题不想回答”和随时结束，正常流程不再要求逐轮人工校对；
- 每轮采访的 AI 提问声和讲述人回答独立保存，结束时按问答顺序自动合并为完整原声；多轮问答汇总为整场 AI 整理稿，家人可选修改后再进入故事整理、人工确认和时间线归档；
- 故事确认前可直接修正标题和正文；归档使用家人最终确认的版本，AI 原始草稿继续独立保留，少量错字不再需要整篇退回重做；
- 回忆档案同时显示尚未完成与已经归档的记录；待生成、待确认和处理中状态都能从档案继续，不再只有最终故事可见；
- 已归档故事可展开查看完整逐轮提问与回答，并播放包含 AI 提问和讲述人回答的完整采访录音；
- 已归档故事可以后补一张家庭照片和人工说明，也可单独移除照片而不影响故事正文与原始录音；没有照片不影响任何记录和传承功能；
- 真实资料的 AI 自动整理与智能追问按整场采访选择一次：原始录音不外发；未开启时自动降级为本地规则清理和安全追问，不阻断采访；
- 家庭人物与关系数据底座、阶段覆盖度，以及只从人工确认故事写入的长期记忆索引；
- “问问家人”只从已人工确认的故事中抽取答案并附故事、原声来源；没有证据时明确说不知道，并可一键生成待采访问题；
- 待采访问题队列会保留还没有答案的家庭问题；已由家人确认或完成核对的补充也能参与检索，并明确标成“家人补充”，不冒充老人本人原话；
- 声音故事馆、可补充年份/地点/主题的人生轨迹，以及不覆盖老人原话的家庭补充、纠错和不同记忆；
- 主题相册会按家人确认的标签聚合照片；家人补充支持“已确认、存在不同记忆、完成核对”状态；
- 老照片人物手工标注：只允许家人确认人物，不做人脸识别，也不自动猜测人物、地点或年代；
- 开放格式传承包：可下载带离线搜索网页、JSON、原声、照片和 SHA-256 清单的 ZIP，不依赖聆年软件，也不包含密钥与恢复材料；
- 指定家人接管的家庭安排记录；当前只记录线下交接意愿，不冒充在线账号权限转移或离世检测；
- 生成式媒体能力目录：老照片修复副本、人物讲述视频、故事情景视频和授权声音复刻均具备独立授权、外部上传和费用边界，但付费供应商尚未接入；
- 零费用本机预制作包：可为老照片修复、人物讲述或故事情景视频整理原始素材、SHA-256、授权清单、修复计划或逐句分镜；只生成 ZIP，不上传、不调用模型、不产生费用；
- 生成成片本机验收闭环：登记故事、真人授权、外部上传范围和单次预算；导入 MP4 时检查格式、大小、结构和预算；成片先进入待验收区，六项检查全部通过才允许标记为可用，驳回时必须保留具体原因；
- 家庭成员与关系维护界面：新增、改名、建立/删除关系和删除普通成员；讲述者不能在家谱界面误删；
- 本机应用内提醒：不接微信、短信、邮件或系统通知，“不要再问”会暂停同话题提醒；
- 版本化 Markdown 与打印版 PDF 回忆录：只使用人工确认故事，保留来源清单与 SHA-256 完整性校验；PDF 失败不影响 Markdown；
- `/keepsake` 原声视频念想：从回忆档案进入，不增加第五个手机底部导航；支持选择 1～10 篇有原声的故事、四项单次授权、进度、刷新恢复、失败重试、播放、版本历史和 MP4 下载；
- 本机 `imageio-ffmpeg` 合成 H.264 + AAC 720p MP4；有照片时使用原照片，没有照片时生成本地故事卡，画面固定标注“家庭记忆整理 · 原始录音 · 非实时影像”；
- 视频任务、标题和授权记录进入 SQLite；真实资料模式下标题、确认人和视频文件继续使用家庭主密钥加密，下载前校验尺寸和 SHA-256；
- 本机整库备份和离线恢复演练已覆盖第四阶段视频，恢复时会认证解密全部加密媒体，不把主密钥或恢复口令写入备份；
- 照片/老物件图片触发：校验 JPEG、PNG 和 WebP 真实内容、尺寸与 SHA-256，只提问安全的固定问题，不识别人脸或猜测人物、地点、年代与事件；
- 390、768、1280、1440 px 响应式布局、48 px 核心触控目标、键盘焦点、状态播报、减少动画和自动无障碍扫描。
- 邀请码只读演示：12 小时 HttpOnly 签名会话、同源校验、基础登录限流、会话篡改/过期校验、直链保护、退出后立即重新锁定。

## 使用真实本地 FunASR

在根目录 `.env` 中设置：

```dotenv
ASR_PROVIDER=funasr
ASR_MODEL_ID=paraformer-zh
MODEL_CACHE_ROOT=./backend/.model-cache
```

首次转写会下载约 1 GB 的模型到 `backend/.model-cache/`。该目录不会进入 Git。默认 mock 模式不会下载模型。
