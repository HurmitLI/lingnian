# 第十三阶段平台管理后台验收记录

> 日期：2026-09-04
>
> 状态：代码、自动测试与正式云端发布完成，等待产品管理员登录验收

## 本阶段解决的问题

- 不再依赖“第一个账号自动成为管理员”这条隐藏规则；后台会明确显示当前平台管理员的称呼和登录名。
- 新家庭体验码具有固定网页入口：`/admin`。平台管理员可随时生成、复制邀请说明、查看使用状态和撤销，不需要打开终端。
- 后台可查看账号、家庭归属、账号状态、权限和最近登录时间，但不能读取家庭故事、录音和照片。
- 平台管理员可停用或恢复普通家庭成员；停用后已有登录立即失效。
- 平台管理员和家庭管理员受到保护，必须先完成相应管理权交接，不能被误停用。
- 登录页新增“平台运营人员进入管理后台”，登录成功后返回后台。

## 自动验证

- 后端正式鉴权测试覆盖平台概况、账号列表、管理员保护、普通成员停用、旧会话失效和恢复账号。
- 前端测试覆盖管理员登录返回后台、后台账号显示和网页生成体验码。
- 后端全量测试、前端全量测试、代码检查、类型检查和 Next.js 正式构建通过。
- 正式云端真实浏览器已确认管理员身份、固定发码入口、账号列表和登录页后台入口均正常显示。
- 线上生成、显示和撤销一枚临时测试体验码成功；测试码已撤销，没有留下可使用的邀请码。

## 人工验收

1. 打开正式版登录页，点击“平台运营人员进入管理后台”。
2. 使用平台管理员账号登录，确认页面明确显示管理员登录名。
3. 点击“生成新家庭体验码”，复制完整邀请说明。
4. 用另一个浏览器通过该码建立虚构家庭，返回后台确认账号和家庭数量增加。
5. 如虚构家庭内再建立普通成员，可验证停用和恢复；不要用真实家人账号做停用测试。
