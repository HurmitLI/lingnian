# 聆年第十四阶段故事成片产品化开发记录

> 日期：2026-09-04
>
> 分支：`聆年第十四阶段故事成片产品化分支`
>
> 状态：代码、自动测试、正式云端发布和真实浏览器检查完成；完整长片质量仍需按每条任务逐片验收

## 本阶段解决的问题

1. 年份不再按普通数量朗读。界面和家庭档案继续保存原文；只有送入语音合成和生成制作包的朗读文本会把 `1928年` 处理为 `一九二八年`。
2. 提交生成任务前即可看到已确认故事标题和最多三段原文，先确认“这次准备讲什么”，再决定是否授权发送素材。
3. 照片和视频继续在家用生成节点后台制作。页面显示当前阶段、进度条和宽松的时间范围，并明确说明可以离开页面，回来后继续查看。
4. 页面记住任务上一次状态。任务从排队或生成中进入“等待验收”或“失败”时，会在家庭空间内提示，不依赖浏览器系统通知权限。
5. 失败任务不再要求家庭成员联系平台管理员。家庭成员可以在原任务上点击“重新制作”，故事和素材无需重新采访或重新上传。
6. 生成制作包同时保存 `narration` 原文和 `spoken_narration` 朗读文本；生成节点可以使用朗读文本合成旁白，但不得把它回写成新的家庭事实。

## 时间显示口径

- 老照片修复：节点领取后通常约 3–10 分钟。
- 人物讲述视频：节点领取后通常约 12–35 分钟。
- 故事情景视频：节点领取后通常约 25–70 分钟。
- 开始生成后，页面会按上报进度缩小剩余范围；这是体验提示，不是服务时限承诺。模型首次加载、显存不足、镜头数和分辨率都会让实际时间变化。

## 数据和权限边界

- 仍然需要逐项确认素材权利、不冒充真人、真人专项授权和本次外发范围。
- 任务只会发送给家庭明确连接的生成节点；ComfyUI 不开放公网端口。
- 生成结果只进入待验收区，不会因为“生成成功”自动进入正式家庭展示。
- 本阶段没有启用声音复刻，也没有新增第三方付费视频供应商。

## 尚未冒充完成的部分

- 当前已经验收通过的是一条 10.5 秒多镜头情景样片，不等于 60–90 秒正式影片模板已经达到稳定量产质量。
- 人物口型、长片镜头一致性、1080p 输出、实际显存峰值和完整长片耗时，仍需用虚构或明确授权素材逐条验收。
- 声音复刻继续保持关闭；启用前需要本人专项授权、声音样本管理、撤销机制和单独质量验收。
