## 上线形态

本次只发布一个前端只读演示应用，不发布后端、SQLite、本机密钥、模型 Key 或真实家庭档案。受邀人输入邀请码后，可以看到虚构人物“沈素琴”的完整样片：家庭影像、故事文字、照片和产品处理流程。

公网演示和本机私密完整版互相隔离：

- 演示版没有录音、上传、家庭管理、数据库和模型调用入口。
- 公网包内只有虚构样片素材，不包含根目录 `.env` 和 `data/` 内容。
- 本机完整版仍只绑定 `127.0.0.1`，不因本次发布而改变。

## 邀请码与会话安全

- 邀请码只在服务端校验，使用 SHA-256 等长比较，不进入浏览器代码。
- 登录成功后签发 12 小时有效的 HMAC-SHA256 会话，Cookie 使用 `HttpOnly`、`SameSite=Strict`，公网 HTTPS 下同时使用 `Secure`。
- 登录接口校验同源请求，单个运行实例内限制连续错误尝试。邀请码使用高熕随机值，不依赖简单短口令。
- 未登录时，`/showcase` 跳转登录页；照片和视频直链返回 401。退出后 Cookie 立即失效。
- 邀请码和会话密钥不进入 Git、前端公开变量、部署包和上线记录。

## 云端配置

计划使用现有北京区域的 `AI-gateway`，新建一个独立应用 `lingnian-invite-demo`：

- 框架：Next.js 16.3，静态页 + Node.js 路由处理器。
- 运行时：veFaaS `native-node20/v1`。Next.js 官方最低要 Node 20.9，当前代码不使用 Node 22 专属 API。
- 规格：0.5 vCPU、1 GiB 内存、最小实例 0、最大实例 3，无预留实例。
- 构建：`npm ci && npm run build`。
- 启动：`npm run start`，端口 `3011`。
- 服务端环境变量：`DEMO_PUBLIC_MODE`、`DEMO_INVITE_CODES`、`DEMO_SESSION_SECRET`。三者都不使用 `NEXT_PUBLIC_` 前缀。

## 费用边界

当前账户 2026 年 8 月已产生约 17.18 元费用，主要来自已有函数服务。新演示应用采用按量计费和零预留实例；无访问时不保持常驻实例。根据火山引擎当前官方按量价格，费用主要由调用次数、执行时间、内存和公网流量构成；视频为 2.5 MB，少量邀请体验的流量可控。

本次提议的新增月费预算上限是 20 元。没有产品经理对这个费用边界的明确确认，不创建新应用。

## 上线后必验

1. 无痕窗口打开公网根地址，必须进入邀请码页。
2. 未登录直接访问视频和照片，必须返回 401。
3. 错误邀请码不能进入；正确邀请码能打开样片。
4. 播放视频，确认画面、声音、字幕和 1.25 倍语速均正常。
5. 用手机浏览器重复登录、播放和退出。
6. 检查 veFaaS 发布状态、线上日志和最小/最大实例数。
