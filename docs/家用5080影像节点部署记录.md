# 家用 5080 影像节点部署记录

> 实施日期：2026-09-04；测试素材全部为 AI 生成的虚构人物/场景，不含家庭资料。

## 机器与安装目录

- Windows 64 位，build 28000；内存 31.2GB。
- NVIDIA GeForce RTX 5080，驱动 610.88，显存 16303MiB，计算能力 SM 12.0。
- C/D/E 盘实施前空余 90.1/547.3/1410GB。选择 `E:\LingNianAI`，不在 Git 仓库存模型。
- ComfyUI：`E:\LingNianAI\ComfyUI`，commit `30bdda1ef13a3a34fce2cd2fec633f15d832122a`，版本 0.34.0。
- Python 环境：ComfyUI 为 `E:\LingNianAI\ComfyUI\.venv`，节点为 `E:\LingNianAI\node-venv`。
- PyTorch 2.14.0+cu130、torchvision 0.29.0+cu130、torchaudio 2.11.0+cu130；使用正式 CUDA 13.0 wheel，无需单独安装 CUDA Toolkit。
- 输出：`E:\LingNianAI\ComfyUI\output\lingnian` 与仓库忽略目录 `local_node\outputs`。

## 启停与安全

- 双击 `启动聆年影像节点.cmd`；会启动 ComfyUI 和主动轮询节点。
- 双击 `健康检查.cmd` 查看 GPU/ComfyUI 健康信息；双击 `停止聆年影像节点.cmd` 停止。
- `启用登录后自动启动.cmd` 与 `撤销登录后自动启动.cmd` 提供可撤销的登录启动项，未强制修改系统。
- ComfyUI 启动参数固定 `--listen 127.0.0.1 --port 8188 --lowvram`。实测 `Get-NetTCPConnection` 仅出现 `127.0.0.1:8188`，没有 `0.0.0.0`/公网监听。
- 生产令牌存 Windows 凭据管理器（服务名 `LingNianLocalNode`）；`.env`、运行状态、输出和密钥均被 Git 忽略。

## 降级与遗留问题

- 本轮 4 秒动态是经过真实视频编码的自然轻动态，不是扩散式 Wan 视频；Wan2.1 权重尚未下载和实跑。
- Wav2Lip 的公开权重限制商业使用，本轮没有把它冒充生产可用能力，也没有完成真实口型同步样片。生产须选择商业授权模型后再启用。
- 老照片完成放大和细节增强；自动上色工作流尚未实跑。
- 节点已实现模拟云端闭环、授权/成本闸门、幂等状态和恢复；正式 HTTPS 协议需云端端点与令牌后联调。
- 不需要更新驱动，也不需要重启 Windows。

## 工作流与影片结构

工作流在 `local_node/workflows`。完整影片应由脚本按故事段落生成场景图，穿插照片修复副本、轻动态/短视频、原声和字幕，再以短交叉淡化转场合成；不得退化为整段固定照片加字幕。当前 FFmpeg 随 `imageio-ffmpeg` 安装在节点虚拟环境中。
