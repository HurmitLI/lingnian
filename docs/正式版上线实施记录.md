## 已完成的上线改造

- 邀请码建账、安全 Cookie 登录、退出、过期与撤销。
- 所有家庭资源从当前登录会话推导家庭范围，跨家庭 ID 返回不可见。
- 第一个账号成为家庭管理员；管理员可生成七天有效、仅可使用一次的家人邀请码、撤销未使用邀请码、查看家庭成员和移除成员访问。
- 成员被移除后，其所有已登录会话立即失效；账号改密后，除当前设备外的旧会话失效。
- 业务 SQLite 在云实例本地运行，每次成功修改后生成完整性校验的不可变快照并写入私有 TOS；实例重建时自动选择最新完整快照恢复。
- 录音、照片、回忆录和视频目录直接位于私有 TOS 挂载目录，后端读写前继续做家庭归属、路径、大小、SHA-256 与加密校验。
- 正式前端只允许同源麦克风，同时禁用摄像头和定位；虚构只读演示继续禁用麦克风。
- 登录失败增加了滑动时间窗限制；每个请求返回 `X-Request-ID`，服务端日志只记录请求号、方法、路径、状态和耗时，不记录家庭内容。
- `/health` 检查进程，`/readiness` 同时检查数据库和持久存储是否就绪。
- 正式后端保持最大一个实例，但将单实例请求并发提高到 10，避免首页同时读取人物、回忆、提醒和书册时被网关拒绝；此调整不增加常驻实例。
- 正式网页的读取请求增加短延迟自动重试，成功读取后自动清除旧失败提示。
