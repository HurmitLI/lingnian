# 聆年 V0.9 发布说明

> 发布定位：家庭私密内测候选版
>
> 当前状态：本机版本已完成，尚未公网部署

## 这一版能做什么

- 为同一家庭建立和切换多位讲述者档案。
- 用一个温和问题或一张照片、老物件触发回忆。
- 在浏览器录音、试听和上传，原始录音保存在本机。
- 使用本地 FunASR 转写，由家人校对后再整理故事。
- 只有人工确认的故事才进入回忆档案和长期记忆。
- 查看原声、照片、人生阶段覆盖和家庭关系。
- 生成 Markdown、PDF 回忆录和可下载的本机原声视频。
- 使用 Mac 钥匙串主密钥、离线恢复包、整库备份和恢复演练保护家庭资料。

## 这一版明确不做什么

- 不克隆讲述者声音，也不让模型模拟本人说新内容。
- 不驱动老照片张嘴，不生成虚构人物影像。
- 不自动公开分享，不把原始录音上传给千问或第三方视频平台。
- 不提供任何人都能注册的公网入口。
- 不把当前本机 SQLite 和媒体目录直接当成线上持久化方案。

## 隐私与授权边界

- 原始录音只允许本机转写。
- 人工校对文本默认不发送云模型；每次发送都需要与文字哈希绑定的单次明确授权。
- 原声视频只使用已人工确认故事和原始录音；授权只使用一次，素材变化后自动失效。
- 密钥、恢复口令、恢复包、API Key 和家庭内容不进入 Git、前端日志或普通技术监控。

## 当前已知限制

- 只适合当前 Mac 上的本机家庭使用，其他设备不能长期独立访问。
- 没有正式登录、家庭邀请、撤销成员和家庭间数据隔离。
- 没有线上数据库、对象存储、异地自动备份和线上故障告警。
- 手机访问本机服务只用于临时同网验收，不能替代 HTTPS 正式地址。
- 方言、环境噪声和老人发音可能影响本地转写，需要家人校对。

## 下一版本方向

V0.9 人工验收后进入 5B 私密上线：先完成登录隔离、可靠存储、备份恢复、HTTPS 和监控，再邀请少量家庭内测。声音克隆与生成式老照片视频属于上线后的独立版本，不与 5B 混在一起开发。
