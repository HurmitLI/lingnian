# 第三阶段真机验收清单

> 只在用户本人准备好手机、并明确同意临时局域网访问后执行。

## 启动前

- 手机和 Mac 连接同一可信 Wi-Fi。
- 本次服务只用于验收，不使用酒店、咖啡店等公共网络。
- 先停止日常本机服务：`./scripts/stop_local.sh`。
- 再启动真机验收：`./scripts/start_phone_acceptance.sh`。

脚本会生成本地验收 CA 和含当前局域网 IP 的 30 天服务证书；私钥只保存在被 Git 忽略的 `.runtime/phone-cert`，下载端口只提供公开 CA 证书，不提供任何私钥。

## 手机上

1. 按终端显示的地址，用 Safari 下载 `niannian-phone-ca.cer`。
2. 在“设置”中安装已下载的描述文件。
3. 进入“设置 → 通用 → 关于本机 → 证书信任设置”，为该验收 CA 开启完全信任。
4. 用 Safari 打开终端显示的 `https://Mac主机名.local:3011`；证书同时保留当前局域网 IP 作为备用地址。
5. 进入“开始记录”，选择一个测试话题。
6. 点击“开始录音”，允许麦克风，讲一句不含真实隐私的测试内容。
7. 点击“停止录音”，试听，然后确认页面按钮和底部导航是否清楚、好点。
8. 如需验证上传，只上传刚才的测试录音，不使用真实家庭录音。

## 通过标准

- Safari 没有证书警告，麦克风权限可以正常询问。
- 录音计时会增加，停止后能试听。
- 页面没有横向滚动，底部导航没有遮住主操作。
- 主要文字不需要放大才能阅读，按钮容易点到。
- 拒绝麦克风后能看到清楚的处理办法，再允许后可以重试。

## 验收后

- 在运行脚本的终端按 `Control-C`，停止局域网服务。
- 在手机中删除“Niannian Phone Acceptance CA”描述文件和证书信任。
- 重新运行 `./scripts/start_local.sh`，恢复只绑定 `127.0.0.1` 的日常模式。
