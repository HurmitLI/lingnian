# 聆年第十六阶段家用影片执行器开发记录

> 日期：2026-09-05
>
> 分支：`聆年第十六阶段家用影片执行器分支`
>
> 状态：家用 v2.0.2 已完成上传、噪纹与逐镜主体修复；最新 45 秒样片正常回传，仍有物件样式和色彩风格不一致，保持待验收，尚未通过正式成片终验

## 本阶段目标

把第十五阶段已经上线的“纪实故事影片任务与分镜契约”真正交给家庭电脑执行，而不是继续依赖旧版短样片脚本。节点只处理家庭逐项授权的任务，不接受云端反向连接，不开放 ComfyUI 公网端口。

## 已开发能力

1. 新增独立的 `generation-worker` Python 包和 `lingnian-worker` 命令，支持持续运行、单次执行、环境体检和把密钥写入系统凭据库。
2. 节点从云端领取独立租约，下载 `.lnpkg`，用节点密钥派生的 AES-GCM 密钥解密，并在落盘前验证加密完整性。
3. 解压会阻止绝对路径和上级目录穿越；照片和原声逐项核对 SHA-256；没有单次外发授权、v2 分镜或完整素材时拒绝执行。
4. 标题卡、来源卡和档案照片在本机制作；纪实环境镜头通过 `127.0.0.1:8188` 调用 ComfyUI API 工作流。
5. 为适配 16GB RTX 5080，默认单个环境镜头只生成最多 5 秒，然后规范为目标镜头时长，不让模型一次生成 45–90 秒长片。
6. 所有镜头统一为 1280×720 或 720×1280、24fps，并在本机烧录字幕；最后使用原始录音合成，不调用 TTS，也不克隆声音。
7. 原声超过目标片长 1 秒以上时停止并返回可理解的错误，避免从一句话中间强行截断；短于片长时只补静音尾部。
8. 每完成一个镜头保存文件摘要并上报云端检查点。节点重启或任务重领后，只复用摘要正确的镜头，损坏镜头会重新制作。
9. 回传前读取实际时长和分辨率；与授权规格不一致时不上传。成功结果只进入待家庭人工验收区，上传后删除本地任务目录。
10. Windows 安装程序完成 Python 环境、依赖、非敏感配置、系统凭据、环境体检和登录自启任务；节点密钥不写进 Git 或普通日志。
11. 平台管理后台新增节点程序版本显示，并把“复制连接配置”的变量名更新为 v2 执行器可直接识别的 `LINGNIAN_BACKEND_URL`。
12. v2.0.1 为每个镜头使用包含原文、镜头号和重试次数的独立随机种子；同一任务出现重复空镜时自动换种重试，仍重复则阻止低质量成片回传。
13. v2.0.1 可沿 KSampler 的正向/负向条件连接自动改写常见 ComfyUI API 工作流，不再要求老师提供的固定提示词工作流必须人工逐个加入占位符；无法绑定提示词、随机种子或输出文件名时，`doctor` 会明确拒绝启动。
14. 云端分镜压缩改为合并相邻短句而不是抽样丢句，确保年份、地点和物件不被遗漏；每个空镜都带当前原文、完整故事上下文、年代约束和禁止无关城市航拍的要求。
15. v2.0.2 从动态空镜的多个时间点提取粗粒度画面指纹并写入断点，不再依赖容易受视频容器元数据影响的文件摘要。节点重启后也能跨断点检查重复画面，旧断点缺少证据的纪实空镜会重新生成，而不是未经检查直接复用。
16. v2.0.2 回传纪实空镜数、真实动态空镜数、唯一画面数和查重结论。云端会在人工验收前自动阻止重复画面、纯静态图片成片、镜头不足和时长不符的结果。
17. 正式前台和平台后台新增最低版本门禁。旧节点可以继续心跳并显示明确升级提示，但不能领取纪实影片任务；它是唯一在线节点时，家庭页面也会阻止新任务提交，避免白跑算力。

### 噪纹修复后的第二轮复验

- 家用修复 `3f0dad7` 已同步：将模型生成尺寸与最终成片尺寸分开，当前 SD1.5/AnimateDiff 使用 512×320、16 帧短片，Euler/normal、20 步、显式运动模型噪声计划；成片仍输出 1280×720。16 帧/8fps 的原始动态镜头仅 2 秒，会被延展到分镜时长，不能称作连续生成的 45 秒画面。
- 新 45 秒样片已正常生成回传，噪纹消失；但浏览器实看约 19 秒蓝布包段落仍是火车，约 34 秒为明显失真的老式机车，逐镜语义与时代观感仍不合格。已再次驳回，不进入正式展示。
- 代码复核发现英文提示抽取会同时读取完整故事和负面约束，造成每个镜头混入其他场景。新增修复：优先当前口述句的画面主体，最长词优先，保持年份含义；日期/年龄独立句只借用原文已有物件，不自行增加事实；主体放在提示开头，避免被长风格说明冲淡。
- 该本地词表只是当前 SD1.5 工作流的有限适配，不是通用翻译器。不认识的中文画面主体现在明确要求补充分镜翻译，不以无关通用画面代替。
- 上述主体修复本机测试为 15 项通过、1 项 FFprobe 环境跳过；家用节点更新及下一条实片仍待验证，不把单测通过写成画面验收通过。
