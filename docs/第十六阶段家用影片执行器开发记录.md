# 聆年第十六阶段家用影片执行器开发记录

> 日期：2026-09-04
>
> 分支：`聆年第十六阶段家用影片执行器分支`
>
> 状态：执行器、Windows 安装程序、自动验证和云端管理可见性已完成并发布；家里 RTX 5080 实机升级仍待执行

## 本阶段目标

把第十五阶段已经上线的“纪实故事影片任务与分镜契约”真正交给家庭电脑执行，而不是继续依赖旧版短样片脚本。节点只处理家庭逐项授权的任务，不接受云端反向连接，不开放 ComfyUI 公网端口。

## 已开发能力

1. 新增独立的 `generation-worker` Python 包和 `lingnian-worker` 命令，支持持续运行、单次执行、环境体检和把密钥写入系统凭据库。
2. 节点从云端领取独立租约，下载 `.lnpkg`，用节点密钥派生的 AES-GCM 密钥解密，并在落盘前验证加密完整性。
3. 解压会阻止绝对路径和上级目录穿越；照片和原声逐项核对 SHA-256；没有单次外发授权、v2 分镜或完整素材时拒绝执行。
4. 标题卡、来源卡和档案照片在本机制作；纪实环境镜头通过 `127.0.0.1:8188` 调用 ComfyUI API 工作流。
5. 为适配 16GB RTX 5080，默认单个环境镜头只生成最多 5 秒，然后规范为目标镜头时长，不让模型一次生成 45–90 秒长片。
6. 所有镜头统一为 1280×720 或 720×1280、24fps，并在本机烧录字幕；最后使用原始录音合成，不调用 TTS，也不克隆声音。
7. 原声超过目标片长 1 秒以上时停止并返回可理解的错误，避免从一句话中间强行截断；短于片长时只补静音尾部。
8. 每完成一个镜头保存文件摘要并上报云端检查点。节点重启或任务重领后，只复用摘要正确的镜头，损坏镜头会重新制作。
9. 回传前读取实际时长和分辨率；与授权规格不一致时不上传。成功结果只进入待家庭人工验收区，上传后删除本地任务目录。
10. Windows 安装程序完成 Python 环境、依赖、非敏感配置、系统凭据、环境体检和登录自启任务；节点密钥不写进 Git 或普通日志。
11. 平台管理后台新增节点程序版本显示，并把“复制连接配置”的变量名更新为 v2 执行器可直接识别的 `LINGNIAN_BACKEND_URL`。

## 当前自动验证

- 执行器 6 项测试通过、1 项按环境跳过，覆盖加密包解密、错误密钥、ZIP 路径穿越、素材摘要、ComfyUI 工作流占位符、四类镜头执行和重启续作。
- 执行器可构建为独立 Python wheel，命令行入口可用。
- 本机没有安装 FFprobe，因此真实 1 秒 MP4 媒体测试按环境条件跳过；家里电脑安装时 `doctor` 会把 FFmpeg/FFprobe 作为硬性条件检查。
- 后端新增安全、可操作的素材包损坏和原声时长不匹配提示。
- 前端管理后台测试覆盖节点 v2 版本展示和新版连接配置。

## 正式云端验证

- 正式后端已发布为第 31 个版本，健康检查、数据库和持久化存储均就绪。
- 正式前端已发布为第 27 个版本。
- 后端全量 88 项、前端全量 49 项测试通过，前端 TypeScript、ESLint 和正式构建通过。
- 已在正式 `/admin` 页面实测节点版本能够显示，生成任务名称统一为“纪实故事影片”。
- 当前在线的家用 RTX 5080 节点仍报告 `0.2.0`，说明它尚未安装本阶段的 `lingnian-worker/2.0.0`；因此本阶段没有冒充实机升级完成，也没有提交新的 GPU 任务。

## 实机完成标准

1. 家里电脑从本分支安装 v2 执行器，`doctor` 显示云端、系统凭据、ComfyUI、工作流和媒体工具全部就绪。
2. 正式后台在线节点显示 `lingnian-worker/2.0.0`，而不是旧版心跳。
3. 用虚构或明确授权素材提交一条 45 秒任务，确认多镜头生成、进度、断点、原声、字幕、时长和分辨率全部正确。
4. 家庭人工确认镜头连贯、没有新增档案事实后才能验收通过；完成前不宣传长片已经稳定量产。
