# 聆年正式版本功能审计与补全记录

> 日期：2026-08-31  
> 分支：`正式版本完善分支`  
> 审计口径：`niannian.md`、第一至第五阶段开发手册、当前 FastAPI 接口与正式 Web 页面

## 结论

正式版本不是只有录音的空壳。V0.9 已经覆盖“建档 → 回忆触发 → 录音 → 本机转写 → 人工校对 → 忠实整理 → 人工确认 → 档案/回忆录/原声视频 → 本机加密与恢复”的完整本机闭环。

本轮确认到的主要问题是：功能入口不够产品化、正式界面密度不统一，以及照片档案、故事检索、提醒管理存在前端缺口。上述现有架构内缺口已经补齐。

## 本轮补全

- 正式版桌面主导航增加“原声视频”，不再要求用户先进入档案再寻找入口；手机仍保留四个底部主入口，避免再次拥挤。
- 正式版五个页面统一为紧凑的家庭档案工作台，降低大标题、大留白、厚阴影和演示稿式卡片感。
- 回忆档案增加标题、正文、阶段和照片说明全文搜索，以及人生阶段筛选。
- 时间线接口补充故事所属人生阶段、关联图片地址和家人人工说明；正式档案现在能把照片/老物件和对应故事放在一起。
- 本机提醒增加现有提醒列表和主动关闭入口，补齐后端已有但前端未开放的 `dismiss` 能力。
- 补齐 PRD 中缺失的健康与照护备注；该字段只有在完成恢复演练并启用敏感资料加密后才能保存，数据库明文列只保留加密占位符。
- 长称呼在页面大标题中自动回退为“家人”，完整名称仍保留在讲述者选择器中，避免手机端标题破版。

## 不应伪装成“已补全”的下一版本能力

以下内容需要独立的账号、数据、授权、合规或付费方案，不属于当前本机 V0.9，不能直接把本机 SQLite 和素材目录暴露到公网：

- 公网注册、家庭登录、邀请码账号、跨家庭数据隔离、成员撤销和远程协作；
- 指定后代、在线分享、撤销分享和离世后的权限继承；
- 云数据库、对象存储、异地备份、线上监控和故障恢复；
- 声音克隆、自定义音色训练、模拟本人说新内容；
- 照片口型驱动、数字人和第三方图生视频。

当前邀请码公网地址是隔离的只读产品体验页，不是把本机正式家庭档案直接发布到公网。正式版仍通过 `http://127.0.0.1:3011` 在这台 Mac 使用。
