## 本阶段完成内容

- 首页、记录、回忆档案、原声视频和家庭管理使用统一的页面结构、色彩、字体、按钮、卡片、状态和响应式规则。
- 记录流程整理为“选择回忆 → 留下声音 → 校对原话 → 确认故事”四步，每次只突出当前主要动作。
- 讲述者支持新增、编辑和切换，不再把单条“林奶奶”测试数据表现成固定人物。
- 档案优先展示故事、原声与关联照片；提醒和回忆录导出继续作为低频工具收起。
- 原声视频整理为“选择故事 → 确认授权 → 本机制作 → 播放保存”四步，保留单次授权和本机处理边界。
- 家庭管理按照讲述者档案、讲述意愿、档案安全三层组织，备份与恢复作为低频设置。
- 产品展示名称由“念念”更名为“聆年”；最终 Logo 使用窗边暖灯图形。内部 `niannian` 数据与加密兼容标识保持不变。
