# 第四阶段人工验收清单

> 状态：用户已于 2026-08-29 确认“第四阶段验证通过”。

> 这一步会使用你主动选择的原始录音，在当前 Mac 上生成一份加密 MP4。素材不会上传第三方，不调用千问，不新增平台费用。

## Mac 端

1. 打开 <http://127.0.0.1:3011/archive>。
2. 点击故事下方的“制作原声视频念想”。
3. 先选择一篇你确认愿意留下原声的故事。
4. 确认“视频名称”和“本次确认人”，再阅读并勾选四项原声使用说明。
5. 点击“确认授权并开始本机制作”。
6. 等待页面显示“原声视频已生成”；可以停留、离开或刷新，任务不会丢失。
7. 点击播放，确认：
   - 听到的是原始录音，没有新生成的老人声音；
   - 画面有“家庭记忆整理 · 原始录音 · 非实时影像”；
   - 视频内容与所选故事一致。
8. 点击“下载 MP4 到本地”，确认浏览器完成下载。
9. 刷新页面，确认仍能恢复当前版本并再次播放。

## 通过标准

- 不勾选四项授权时不能开始制作。
- 视频能播放、声音正常、画面清楚，没有被当作真实当下影像。
- 下载和刷新恢复正常。
- 旧故事、原始录音和照片没有被覆盖或删除。
