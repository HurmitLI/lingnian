# 本地视频生成与验收

本地链路支持：虚构文字主线 → 人物参考图 → 分镜参考图 → 动态短镜头 → 逐镜审核 → 原速拼接与字幕。

使用自有 RTX 5080、ComfyUI、FLUX 2 Klein 4B 和 Wan 2.2 TI2V 5B。`generation-worker/scripts/local_story_trial.py` 限定本机 ComfyUI 地址，保存任务标识以恢复任务，素材审查绑定 SHA256 和主线动作。`assemble_local_story.py` 要求全部镜头通过审核、原生帧数充足、音频足60秒，拒绝重复素材，并处理中文长字幕换行。

已完成一个虚构《窗边的茉莉》样片：13个生成镜头，60秒、24fps、1280×720；未用循环、慢放、静帧补时。已逐镜检查及整片抽帧检查，本机浏览器播放至60秒结束。声音复用既有虚构配音，非家人原声。

本地产品代码同步了分镜规划、无人镜头的提示词处理、生成任务和结果校验。一次经筛选重做的样片不代表任意输入一次成功率100%，也不代表人物照片一致性已经验证。轻微动作、花叶细节与跨镜面部光影仍有变化；未解决所有复杂交互动作。

生成素材、模型、运行数据、凭据和临时压缩包不入仓库。本次只同步 GitHub，没有发布火山引擎。
