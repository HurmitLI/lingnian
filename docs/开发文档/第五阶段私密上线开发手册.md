# 聆年 · 第五阶段 5B 私密上线开发手册

> 配套声明：`第五阶段私密上线技术适配声明.md`
>
> 当前状态：完成 5B-0 盘点，等待关键产品决策

## 一、完成定义

5B 完成不以“获得一个公网网址”为准，而以以下结果同时成立为准：

- HTTPS 地址在电脑和手机可访问。
- 未登录请求被拒绝，错误邀请凭据被拒绝，退出后令牌失效。
- A 家庭无法读取、修改、下载或推断 B 家庭的任何资料。
- 服务重新发布或实例重建后，数据库与媒体不丢失。
- 备份可以在空环境恢复，恢复后加密数据和媒体通过完整性验证。
- 密钥、令牌、恢复口令和家庭内容不进入代码包、Git、前端或普通日志。
- 核心链路在真实线上环境完成电脑和手机人工验收。

## 二、开发顺序

### 5B-0 决策与盘点

- 确认快速演示版或正式私密内测版。
- 确认全云私密、本机配对或只同步成果三种隐私模式。
- 确认登录人员、资料上云范围、删除保留规则和预算。
- 检查云账号、实名认证、地域、网关和可用持久化服务。
- 冻结本机第五阶段数据格式，不直接修改真实数据库。

### 5B-1 身份与家庭隔离

- 新增用户、家庭成员、邀请、会话和撤销记录。
- 登录使用 HttpOnly、Secure、SameSite Cookie；浏览器不把长期令牌放进 Local Storage。
- API 从当前会话取得用户与家庭，所有读取和写入都附加家庭范围。
- 对 URL 中的档案、人物、故事、媒体、任务和视频 ID 做对象归属校验。
- 增加无登录、越权读取、越权修改、枚举 ID、退出和过期测试。

### 5B-2 持久化与媒体存储

- 数据库从 SQLite 可迁移到正式持久化数据库，保留 Alembic 迁移链。
- 抽象媒体存储接口，支持本机文件与私有对象存储两种实现。
- 上传先进入隔离临时区，完成类型、大小、哈希和授权校验后再写正式对象。
- 下载和播放必须再次校验登录、家庭归属、文件尺寸和 SHA-256。
- 设计本机资料迁移工具，但迁移真实资料前单独取得用户确认并先做备份。

### 5B-3 云端密钥与恢复

- 把 Mac 钥匙串实现保留为本机模式，新增云端 SecretStore 实现。
- 每个家庭使用独立数据密钥，禁止所有家庭共享同一裸主密钥。
- 恢复包、主密钥和云端封装密钥分开保存，系统不增加后门。
- 明确成员撤销、家庭删除、密钥轮换和灾难恢复规则。
- 在隔离环境完成“备份 → 空环境 → 恢复 → 全量认证解密”演练。

### 5B-4 长任务与媒体处理

- Web 请求只创建任务并返回任务 ID，不在请求生命周期内依赖长时间处理。
- 转写、故事整理和视频合成使用可恢复任务状态与独立工作进程。
- 根据用户选择的隐私模式决定任务运行在云端还是配对 Mac。
- 保留单次模型授权和原声授权；重试不能绕过授权，也不能重复计费。

### 5B-5 可观测性与滥用防护

- 为每个请求生成 `trace_id`，统一脱敏错误格式。
- 登录、上传、模型调用和视频任务增加速率限制、大小限制和并发限制。
- 日志和告警只包含技术元数据；建立敏感字段自动检查。
- 增加健康、就绪和依赖状态检查，区分服务可用与模型/存储降级。

### 5B-6 部署与线上验收

- 前后端分别完成确定性构建，显式指定兼容运行时、启动命令、端口和资源规格。
- 先配置 Secret 和非敏感环境变量，再发布应用。
- 使用同一 Serverless 网关提供 HTTPS；前端代理到后端。
- 完成登录隔离、重新发布持久化、备份恢复、媒体权限和异常场景验收。
- 用户在真实电脑和手机完成最终验收后，才允许邀请其他家庭成员。

## 三、当前差距清单

| 能力 | 当前本机版 | 5B 目标 |
|---|---|---|
| 登录 | 无，依靠 `127.0.0.1` | 邀请制登录、退出、撤销、过期 |
| 隔离 | API 接受资源 ID | 从会话推导家庭并校验对象归属 |
| 数据库 | 本机 SQLite | 可恢复的正式持久化数据库 |
| 媒体 | 本机目录 | 私有对象存储或配对 Mac |
| 密钥 | 单台 Mac 钥匙串 | 每家庭独立密钥与云端封装方案 |
| 后台任务 | Web 进程内执行 | 可恢复的独立任务执行层 |
| ASR/视频 | 本机模型与 FFmpeg | 由隐私模式决定云端或配对 Mac |
| 日志 | 本机日志 | trace_id、脱敏日志和告警 |
| 运行时 | Python 3.11、Node 22～24 | 与云运行时和锁文件一致 |

## 四、测试门槛

- 现有后端 40 项、前端 20 项和桌面/手机核心闭环不得减少。
- 新增身份与越权测试，覆盖所有包含家庭资源 ID 的接口。
- 新增对象存储故障、重复上传、损坏文件、短时下载地址过期和删除测试。
- 新增密钥不存在、密钥错误、轮换中断、恢复包错误和跨家庭密钥误用测试。
- 新增实例重启、任务中断、重复消费和幂等重试测试。
- 线上验收不能使用构建成功或 HTTP 200 代替真实登录、数据隔离与持久化验证。

## 六、当前必须等待用户的事项

以下选择会改变数据库、加密、任务和部署架构，不能由开发者替用户决定：

1. 快速演示版还是正式私密内测版。
2. 全云私密、本机配对还是只同步成果。
3. 第一批谁能登录，以及允许上云的资料类型。
4. 月度费用上限和云账号是个人认证还是企业认证。

这些事项确认后，从 5B-1 开始连续开发；在此之前不登录云账号、不创建计费资源、不上传真实家庭资料。
