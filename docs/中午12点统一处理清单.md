# 中午 12 点统一处理清单

> 日期：2026-09-02
>
> 原则：开发期间遇到外部账号、费用或真人授权就跳过，不让整个任务停住。这里集中列出只有用户能够决定的事项。

## 醒来后先验收，不需要配置任何平台

打开 <http://127.0.0.1:3011/memory>，依次查看：

1. **问问家人**：提一个已有答案的问题，再提一个档案没有记录的问题；确认答案有来源，未知问题可以进入待采访队列。
2. **声音故事**：播放原声并切换故事。
3. **人生轨迹**：检查年份、地点、主题与主题相册。
4. **家人补充**：查看“确认补充、保留为不同记忆、完成家庭核对”。
5. **传家保存**：下载开放格式传承包并解压打开 `index.html`。
6. **影像实验室**：勾选本机整理授权，下载老照片修复、人物讲述或故事情景视频制作包。

## 需要用户决定后才能继续的外部事项

### 1. 人物视频与情景视频供应商

需要选择以下其中一种路线：

- OneThing 云 GPU + ComfyUI，适合后台人工制作与反复复用工作流；
- 按秒计费的视频 API，接入更快，但每次生成直接产生费用；
- 暂不接入，先继续使用本机制作包和零费用快速影像导出。

选择前需要在平台控制台确认实时价格、GPU 显存、磁盘、实例是否已经存在，以及单次和每月费用上限。当前没有创建实例或调用付费视频接口。

### 2. ComfyUI 工作流

需要分别提供或确认实际可运行的 API Workflow JSON：

- 老照片修复；
- 照片加原始录音的人物讲述；
- 故事情景视频。

工作流必须在选定 GPU 上完成短样片验证，确认模型文件、节点版本、输入输出节点和显存占用后，才能接入产品任务队列。

### 3. 真人素材授权

- 人物视频：讲述者本人授权照片与原始录音。
- 声音复刻：本人专项声音复刻授权和合法训练样本。
- 老照片：家庭确认拥有使用权；原图永久保留，只生成修复副本。

没有这些授权时，聆年会继续阻止生成，不使用网络上随意获取的真人声音或肖像。

### 4. 公网家庭账号与二维码原声书

真正可扫描的原声二维码需要稳定的私密网址、账号登录、家庭成员权限和媒体访问控制。本机 `127.0.0.1` 地址不能印成二维码；在这些条件确定前，不生成看似可用但实际失效或泄露隐私的二维码。

## 用户不需要处理的事项

数据库迁移、加密兼容、桌面和手机自动化、传承包、本机制作包、文档及中文分支提交由开发流程自动完成。API Key、邀请码、恢复口令和主密钥不会写进本清单或 Git。
