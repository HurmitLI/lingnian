## 本次解决的问题

- 采访结束后的故事整理失败不再让用户停在原地：千问返回内容即使带有不同 JSON 包装，也会先做兼容解析；仍无法解析时会安全降级为基于已保存整理稿的故事草稿。
- 发送给千问的授权改成一次明确按钮，不再要求先勾选再点击；原始录音仍不会发送。
- 故事人工确认后会直接进入对应人物的回忆档案，不再要求用户自己寻找下一步入口。
- 回忆档案会显示尚未完成的采访、正在整理的任务和待确认草稿，并在后台处理期间自动刷新。
- 已归档故事可以展开完整采访原稿，逐轮查看聆年提问和家人回答；有完整采访录音时会明确标注包含提问与回答。
- 已归档故事可以后补一张 JPEG、PNG 或 WebP 家庭照片及说明，也可以只移除照片，不影响故事正文和采访录音。
- 采访提问声线改用更自然的女声参数，并放慢节奏、降低尖锐感；浏览器离线兜底声线同步调整。

## 产品边界

- 照片完全可选。一张照片可以作为记忆线索，没有照片也可以完成采访、故事、原声、问答和传承包。
- 家庭照片和采访资料仍只进入当前家庭档案；故事生成继续遵守单次发送授权。
- 人物视频、声音复刻和老照片云端修复仍属于外部生成能力，需要真实人物授权、供应商配置和单次费用边界，不混入本次核心闭环。

## 仍需真人完成的一项检查
