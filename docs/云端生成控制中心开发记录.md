## 本次完成

- 平台管理后台新增“家用生成节点”，平台管理员可以在网页生成一次性连接密钥、查看在线状态、断开节点和查看最近任务。
- 连接密钥只在创建时完整返回，数据库只保存 SHA-256 摘要；节点被断开后旧密钥立即失效。
- 家庭成员只有明确确认素材权利、不冒充他人、真人专项授权和本次加密发送后，任务才会进入家用节点队列。
- 任务支持等待、领取、执行进度、五分钟租约、断线释放、最多三次自动重试、家庭取消、平台人工重试和结果回传。
- 节点只通过出站 HTTPS 主动访问云端。ComfyUI 不需要也不允许向公网开放 8188 端口。
- 云端发送给节点的 ZIP 会再次使用 AES-256-GCM 加密；加密密钥通过节点连接密钥、任务 ID 和 HKDF-SHA256 派生，不在任务表中保存。
- 节点回传的图片或 MP4 会验证文件类型、内容结构、大小和可选 SHA-256；正式家庭开启加密时，落盘后继续使用家庭主密钥静态加密。
- 生成成功只进入“等待家庭验收”。老照片修复检查原图保留和人物一致性；人物视频沿用声音、嘴型、停顿、表情、叙事、时长六项门禁；未通过不进入正式展示。
- 家庭端在页面可见时每八秒刷新排队或执行状态；页面隐藏后停止轮询。
- 节点心跳、空轮询和普通进度不会触发高频云端数据库快照；领取、结果、失败、取消、节点创建与撤销仍会持久化。

## 状态流转

```text
未授权登记 awaiting_provider
         │ 家庭明确授权加密发送
         ▼
等待节点 queued ──领取──> 生成中 processing
    ▲                         │
    │ 断线/可重试失败          ├──结果──> pending_human_review
    └─────────────────────────┤                │
                              ├──不可重试──> failed
                              └──家庭取消──> cancelled

pending_human_review ──家庭验收──> accepted / rejected
```
