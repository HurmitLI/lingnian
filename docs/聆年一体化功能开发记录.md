## 这次解决的产品问题

聆年的核心不再是“录音转文字后做一个字幕视频”，而是把一位家人的原话逐渐整理成可以查、可以听、可以补充、可以理解一生脉络，并能脱离软件长期保存的家庭记忆档案。快速影像导出继续保留，但已经从主导航降级为辅助能力。

## 优先级 1：先让现有故事真正可用

- **问问家人**：输入一个问题，只检索已人工确认的故事；回答附带故事标题、原文片段和原声音频。证据不足时明确说明“档案里还没有答案”，不让模型编造。
- **采访缺口回收**：没有答案的问题可直接保存为下一次采访题目，并跳转到记录流程。
- **声音故事馆**：以故事为单位连续浏览原声、文字、人生阶段和地点。
- **人生轨迹**：家人可人工补充年份、地点、主题和摘要；不确定信息不会被自动猜测成事实。
- **家人补充**：允许保存背景补充、纠错、追问和不同记忆，始终与老人原话并列，不静默覆盖原故事。
- **待采访队列**：档案里没有答案的问题会集中保留，之后可以从原问题继续录音。
- **补充核对**：家人补充可以标记为已确认、存在不同记忆或已完成核对；只有确认或完成核对的内容会进入档案问答，而且来源明确标成家人补充。

## 优先级 2：形成可传给下一代的档案

- **照片人物标注**：家人可以确认老照片中的人物并留下说明；不使用人脸识别，不自动判断身份。
- **主题相册**：根据家人确认的故事标签聚合照片，不用模型猜测主题。
- **开放格式传承包**：下载 ZIP 后可直接打开离线网页，搜索故事并播放随包原声；同时包含结构化 JSON、原始照片、媒体清单和 SHA-256 校验值。
- **指定接管人**：记录未来由哪些家人共同保管、如何线下复核和交接。当前没有公网多用户账号体系，因此不会假装已经完成自动权限继承或离世触发。
- **老照片修复入口**：已建立“保留原图、只生成副本、素材权利确认、逐次外部上传确认、费用上限”的适配协议。未选择供应商前不可点击，不调用接口。
- **二维码原声书边界**：传承包已经具备离线网页和原声，但在没有稳定私密访问地址前不生成不可用或会泄露本机地址的二维码。未来接入家庭账号和稳定链接后再生成二维码。

## 优先级 3：人物与情景视频的正式接入底座

影像与声音实验室列出四种能力：老照片修复副本、人物讲述视频、故事情景视频和授权声音复刻。每种能力都有独立的可用状态、供应商、是否外部上传、是否需要本人授权、预计费用和单次费用上限。

当前没有配置自动供应商，所以页面会明确显示“尚未启用”。后端允许登记制作任务，必须先确认素材使用权、不用于冒充；人物影像和声音复刻还必须有讲述者本人明确授权。系统没有自动付费执行接口，因此登记任务本身不会产生云 GPU 或模型费用。

现在可以先下载零费用的本机预制作包：老照片修复包包含原图、副本约束和人工复核计划；人物讲述与故事情景视频包包含原始录音、授权照片、故事原文、素材 SHA-256 和逐句分镜草案。制作包仍然不等于成片，也不代表允许第三方上传。

后台生成的 MP4 现在可以导入本机待验收区。导入时校验 MP4 文件头、必要容器结构、500 MB 大小限制、生成方式和实际费用是否超过任务预算；文件在真实资料模式下继续使用家庭主密钥加密。导入成功只会得到“等待家人逐项验收”，不会自动成为正式成片。

人物视频验收固定检查六项：声音完整、嘴型由声音驱动、停顿时闭嘴、表情自然、人物和叙事一致、时长足以承载内容；故事情景视频检查声音、画面运动自然度、叙事一致和时长。当前类型的必检项未全部通过时，后端拒绝“验收通过”；选择驳回则必须写明问题，防止再次把“能播放”误报为“人物讲述完成”。

## 2026-09-02 人物视频实机验证

- OneThing 服务 I 区 RTX 4090 按实时页面价格 ¥0.033/分钟短时启动。MuseTalk 对完整输入一次性做人脸关键点预处理时会在 24 GB 显存上失败；按 2 秒切片后，8 秒短样片和 45 段、88.49 秒完整旁白均稳定完成。
- 完整视频规格为 512×640、25 fps、H.264 + AAC。逐帧抽查覆盖片头、片尾、多个分段接缝与停顿区间，人物身份和背景稳定，嘴型由音频驱动，停顿时能收口。
- 发现并修复 45 段 AAC 直接拼接造成的累计编码延迟：最终文件保留合并后的视频画面，并重新封装原始 88.49 秒旁白，避免中途静音逐渐错位。
- 成片已在 Chrome 实际加载并播放，随后导入本机验收台。技术项可验证，但旁白与所选《一段愿意留给家人的回忆》尚未完成语义核对，声音清晰度仍需家人真人听审，因此填写原因后驳回；系统确认它不会进入正式展示。
- 页面登记本次费用约 ¥0.99（按两轮运行时长估算，不等于平台最终账单）。验证结束后再次打开实例页，确认 4090 为“已关机”，计费状态为“未开始计费”。
- 浏览器实测同时发现任务登记成功后调用 `event.currentTarget.reset()` 会因 React 异步事件对象失效而报错。现已在发起异步请求前保存表单元素引用，刷新后错误不再出现。

## 数据与安全

- 新增故事资料、家人补充、传承安排、人物标注和生成准备记录五类数据表。
- 在真实资料模式下，故事地点、主题、摘要、补充内容、标注说明、交接安排和操作人等敏感字段沿用家庭主密钥加密。
- 原始录音和照片仍留在本机；“问问家人”使用本地检索，不把提问或档案发给大模型。
- 传承包不包含主密钥、恢复口令、恢复包、API Key 或模型凭据。

## 尚需用户醒来后决定的外部事项

以下不是代码故障，而是需要真实授权、供应商和费用选择的边界：

1. 确认 MuseTalk 是否作为人物视频后台制作路线；老照片修复、情景视频和声音复刻仍需另外选择供应商或工作流。
2. 下一次人物视频先确认“故事原文、对应原声、授权照片”三者属于同一个已确认故事，并由家人真人听审声音与语义。
3. 确认哪些家庭素材允许上传第三方，以及单次和每月预算。
4. 需要公网家庭账号时，确定账号、成员权限、稳定私密链接与继承规则；届时才能做真正可用的二维码原声书和在线权限交接。
