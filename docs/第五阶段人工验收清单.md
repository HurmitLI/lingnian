## 一、电脑端

1. 打开首页，确认左侧“聆年”名称和窗边暖灯 Logo 看起来正常。
2. 确认首页只有“开始记录一段回忆”一个最突出的主要动作，最近故事和统计不会抢注意力。
3. 进入“开始记录”，确认四个步骤容易理解，话题选择和照片/老物件入口不会显得拥挤。
4. 进入“回忆档案”，确认故事正文、原声视频入口和“保存与维护”层级清楚。
5. 点击“制作原声视频”，只检查故事选择、四项授权和历史版本；不需要真的提交授权。
6. 进入“家庭管理”，确认讲述者、讲述意愿和档案安全三块容易找到。
7. 展开一位讲述者的编辑区，确认可以看懂怎么改名和称呼；不想修改时直接收起即可。

## 二、手机端

1. 用手机打开当前验收地址，确认底部四个入口不会遮挡内容。
2. 分别打开首页、开始记录、回忆档案和家庭管理，确认没有横向滚动，主要按钮容易点到。
3. 在记录页确认一次只突出一个主要动作，不会同时出现大量按钮。
4. 在档案页确认先看到故事，再看到低频工具。
5. 在家庭管理页确认讲述者操作在前，安全与备份没有占满首屏。
