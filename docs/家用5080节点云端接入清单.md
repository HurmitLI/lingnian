# 家用 RTX 5080 节点云端接入清单

这份清单交给家用 Windows 电脑上的 Codex。它只描述云端已经提供的接口与安全约束，不包含连接密钥、家庭资料或生产账号密码。

## 获取连接配置

1. 用平台管理员账号打开正式版 `/admin`。
2. 在“家用生成节点”中点击“生成一次性连接密钥”。
3. 点击“复制家用电脑连接配置”。
4. 把 `LINGNIAN_NODE_TOKEN` 写入 Windows 凭据管理器或仅本机可读的环境文件；不要写进 Git、日志、截图或聊天。
5. 如果密钥泄露，立即在 `/admin` 断开该节点并重新生成。

家用电脑把复制配置中的 `LINGNIAN_API_BASE` 写入被 Git 忽略的 `local_node/config.json`；令牌则通过 `设置云端连接.cmd` 直接录入 Windows 凭据管理器。启动脚本不会从命令行参数或普通配置文件传递令牌。

## 节点连接原则

- 节点主动通过 HTTPS 访问正式后端，不接受云端反向连接。
- ComfyUI 只监听 `127.0.0.1:8188`。
- 默认轮询间隔由心跳响应给出；当前为 8 秒。
- 节点不能列出家庭账号、故事或照片，只能领取已经逐项授权且能力匹配的任务。
- 每个任务都有独立租约。没有正确的节点密钥和任务租约，素材包、进度和结果接口都会拒绝。

## API 顺序

所有节点接口使用：

```http
Authorization: Bearer <LINGNIAN_NODE_TOKEN>
```

1. `POST /api/v1/generation-worker/heartbeat`
   - 上报软件版本、显卡摘要和实际能力。
2. `POST /api/v1/generation-worker/tasks/claim`
   - 没有任务返回 `null`；有任务返回任务 ID、独立租约、素材包地址、费用上限和尝试次数。
3. `GET /api/v1/generation-worker/tasks/{任务ID}/package`
   - 额外请求头：`X-Lingnian-Lease: <租约>`。
4. `PATCH /api/v1/generation-worker/tasks/{任务ID}/progress`
   - 上报 0～99 的进度和普通中文阶段说明，同时续期五分钟租约。
5. 成功时 `POST /api/v1/generation-worker/tasks/{任务ID}/result`
   - multipart 字段名为 `result`，费用字段为 `actual_cost_cents`。
   - 请求头可带 `X-Content-Sha256`，云端会与实际文件摘要核对。
6. 失败时 `POST /api/v1/generation-worker/tasks/{任务ID}/fail`
   - 上报大写错误码、脱敏说明和是否可以重试。

## 加密素材包格式

文件扩展名为 `.lnpkg`，二进制结构为：

```text
LINGNIANPKG1 | 12字节nonce | AES-GCM密文 | 16字节tag
```

派生 32 字节 AES 密钥：

- 算法：HKDF-SHA256
- 输入密钥：完整 `LINGNIAN_NODE_TOKEN` 的 UTF-8 字节
- salt：任务 ID 的 ASCII 字节
- info：`lingnian-generation-package-v1`
- AES-GCM AAD：任务 ID 的 ASCII 字节

解密后的 ZIP 包含 `manifest.json`、已确认故事、人工复核分镜，以及当前生成类型必需的授权照片和原声。节点处理完必须清理明文临时目录；失败日志不得写入故事正文、人物姓名、原声内容或连接密钥。

## 云端已支持的结果

- `photo_restore`：JPEG、PNG 或 WebP，进入老照片修复待验收区。
- `portrait_video`：MP4，进入人物视频六项待验收区。
- `scene_video`：MP4，进入故事情景视频四项待验收区。
- `voice_replica`：尚未接入节点，不得自行开启。

## 实机验收完成条件

- RTX 5080 能被 PyTorch 和 ComfyUI 稳定识别。
- 真实生成任务可以从云端领取、解密、执行和回传。
- 节点断网或重启后不会重复发布同一结果。
- 家庭取消任务后，节点停止上传结果。
- 生成结果必须在家庭页面人工验收；没有通过前不出现在正式展示。
- 完成一张虚构老照片修复、一段虚构人物口型短片和一段虚构情景短片，记录耗时、峰值显存与工作流版本。
