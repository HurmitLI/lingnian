# 家用 5080 节点云端接入清单

## 已准备

- 节点只主动发起 HTTPS 请求，不接受公网入站；ComfyUI 只在 `127.0.0.1:8188`。
- 任务契约包含：任务 ID、类型、明确授权、真人专项授权、用途、单任务成本上限、预计成本、加密素材清单和 ComfyUI 工作流。
- 节点拒绝无授权、无用途、真人未专项授权和超预算任务。
- SQLite 保存任务唯一 ID、状态、尝试次数和脱敏错误；重启后处理中任务进入重试，成功任务不重复执行。
- 模拟回传使用 AES-256-GCM，并以任务 ID 作为关联数据；生产应使用云端注册公钥封装的每任务数据密钥。

## 云端需要实现的接口

1. `POST /nodes/register`：登记节点公钥、GPU 型号、显存、能力和软件版本。
2. `POST /nodes/{id}/claim`：长轮询/短轮询领取任务，返回幂等任务 ID、授权证明、用途、预算及截止时间。
3. `GET /assets/{id}`：短时签名 HTTPS 下载；素材包必须为认证加密格式并含 SHA-256。
4. `POST /tasks/{id}/progress`：报告领取、下载、生成、上传等阶段及百分比。
5. `GET /tasks/{id}/cancellation`：节点轮询取消状态。
6. `POST /tasks/{id}/result`：分片上传加密结果与清单；服务端按任务 ID 幂等确认。
7. `POST /tasks/{id}/failure`：结构化错误码、可重试标志和脱敏摘要。

所有接口须 TLS，节点令牌应可撤销、轮换并只允许该节点任务范围；下载/上传 URL 短期有效。

## 下一步唯一需要用户提供的内容

正式云端签发的“节点编号 + 一次性节点注册令牌”（不要发在聊天或写进仓库；在本机凭据录入窗口中粘贴）。有这两项后可完成正式 HTTPS 联调。当前未创建任何付费云资源。
