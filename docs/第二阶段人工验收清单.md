# 第二阶段人工验收清单

> 状态：用户已验收通过

> 页面：<http://127.0.0.1:3011>  
> 当前档案只包含测试资料，可用于安全演练。

## 一、必须由你本人完成的安全操作

1. 在“家庭档案安全”中点击“在 Mac 钥匙串中初始化主密钥”。
2. 设置一个至少 12 个字符、只由家庭掌握的恢复口令，生成并下载 JSON 恢复包。
3. 把恢复包交给可信家人离线保管；恢复口令与恢复包分开存放。
4. 在页面重新选择该恢复包并输入口令，确认“恢复验证”变为“已通过”。
5. 选择“已授权非敏感家庭资料”作为本次测试级别，勾选风险确认，再点击“完成加密并启用真实资料”。

不要把恢复口令、API Key 或恢复包发到对话中。主密钥与恢复材料同时丢失后，系统无后门解密。

## 二、功能验收

- 展开“维护家庭成员与关系”，新建两位虚构成员，改名并建立一条关系；刷新后仍存在。
- 把一个话题设为“不要再问”，确认对应入口不可再创建回忆或提醒。
- 用一张不含隐私的测试图片验收“照片 / 老物件”入口，确认问题只邀请讲述，不猜测人物、地点或年代。
- 完成一次虚构录音、本地转写、人工校对、故事整理和确认归档。
- 为当前时间创建一条本机提醒，刷新或重启后确认不会重复显示。
- 生成 Markdown 和 PDF 回忆录，确认只包含已确认故事。

## 三、备份与恢复验收

1. 在安全卡片中点击“生成并验证新备份”。
2. 确认备份状态为 `verified`，然后下载 ZIP 备份。
3. 选择该备份、上传离线恢复包并输入恢复口令，点击“开始完整恢复演练”。
4. 确认页面提示文本、媒体、SQLite 和资产哈希全部通过。

## 四、通过标准

上述项目无阻断问题，且你确认恢复包与口令已分开妥善保管后，第二阶段即可人工验收通过。
