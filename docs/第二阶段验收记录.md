# 第二阶段验收记录

> 状态：开发中  
> 开始日期：2026-08-29

## 已确认产品决定

- 真实家庭录音只在本机使用 FunASR 转写；真实人工校对稿默认不发送千问，单次明确授权后才允许发送最少必要文字。
- 家庭档案主密钥保存在当前用户的 Mac 钥匙串；家庭另行保管受恢复口令保护的离线恢复包；系统不保留后门。
- 第二阶段只实现应用内本机提醒，不接微信、短信或其他对外发送渠道。

## 当前自动化验证

- 后端测试：14 项全部通过；其中新增 5 项安全测试。
- AES-256-GCM：文字往返、错误密钥、上下文串换和密文篡改检测通过。
- 恢复包：scrypt 派生、错误口令、元数据篡改、文件权限 `0600` 和禁止静默覆盖通过。
- Mac 钥匙串：已识别本机原生 `keyring.backends.macOS.Keyring`；尚未在无用户操作的情况下写入正式主密钥。
