# 5B 私密上线输入清单

> 使用时机：第五阶段 5A 最终人工验收通过之后
>
> 原则：先确认范围、费用和隐私，再创建云资源或迁移真实资料

## 一、先选择上线等级

### A. 快速演示版

- 只放虚构测试数据，不上传真实家庭录音、照片和故事。
- 可以快速获得 HTTPS 网址，用于展示页面和基本流程。
- 不承诺长期数据保存、正式家庭登录和完整灾难恢复。
- 适合短期演示，不适合家人真实使用。

### B. 正式私密内测版（推荐）

- 只允许受邀家庭成员登录，不开放公众注册。
- 不同家庭的数据和媒体必须严格隔离。
- 使用可靠数据库、对象存储、加密密钥管理、备份恢复和故障监控。
- 可以保存真实家庭资料，但必须逐类确认上云范围和保留期限。

## 二、需要用户确认的产品决策

1. 谁可以登录：仅你本人、固定家庭成员，还是邀请码邀请。
2. 是否允许同一个账号管理多个家庭。
3. 成员退出、被移除或讲述者本人撤回授权后，资料怎么处理。
4. 真实录音、照片、故事、PDF 和视频分别是否允许上云。
5. 删除后是立即彻底删除，还是保留一段可恢复期。
6. 预计首批有几个家庭、多少成员和大致媒体容量。
7. 使用平台临时域名还是自有域名；自有域名不是首轮必须项。
8. 可以接受的月度费用上限，以及是否允许使用按量计费服务。

## 三、需要用户本人完成的事项

- 登录或注册云平台账号并完成必要实名认证。
- 在创建计费资源前确认费用范围。
- 决定主账号或子账号归属，并按清单开通权限。
- 将密钥只填写到本机安全配置或云平台 Secret，不粘贴进代码、文档和 Git。
- 对真实家庭资料上云、原声使用和家庭成员邀请作最终授权。

## 四、AI 负责完成的工作

- 盘点现有 FastAPI、Next.js、SQLite、媒体目录和加密方案，输出迁移设计。
- 实现登录、邀请码、会话撤销、家庭级权限与数据隔离测试。
- 将业务数据和大文件迁移到适合长期保存的数据库与对象存储。
- 配置 HTTPS、Secret、结构化日志、技术监控、限流和错误脱敏。
- 完成备份、恢复、删除、升级和回滚演练。
- 部署前后端并完成电脑、手机和异常场景的线上验收。

## 五、上线验收门槛

- 未登录无法读取任何家庭资料，A 家庭无法访问 B 家庭数据。
- 服务重启、重新发布和单个实例故障后，故事与媒体仍然存在。
- 备份能在空环境中恢复，恢复后加密媒体可以通过认证校验。
- 音频、照片和视频的上传、播放、下载与删除均受权限保护。
- 日志不包含 API Key、恢复口令、原始录音、完整故事和家庭身份信息。
- 费用、容量、保留策略、删除规则和故障处理方式有明确记录。
- 用户本人在真实手机和电脑上完成登录、记录、归档、播放和退出验收。

## 六、开始 5B 前只需回答的四个问题

1. 选择快速演示版，还是正式私密内测版？
2. 第一批哪些人可以登录？
3. 哪些真实家庭资料允许上云？
4. 每月费用上限是多少？

这四项没有确认前，可以继续做只读技术盘点和迁移方案，但不创建付费云资源、不公开发布，也不上传真实家庭资料。
